Class SceneGeometry

A geometry in a SceneModel.

  • Contains triangles, lines or points
  • Stored in SceneModel.geometries
  • Created with SceneModel.createGeometry or SceneModel.createGeometryCompressed
  • Referenced by SceneMesh.geometry

See @xeokit/sdk/model/scene for usage.
