Class PanelRegistry

Single dispatch point for opening, hiding, and toggling every panel and tool Studio exposes, keyed by panel id rather than a dedicated openX/hideX/toggleX method per panel.

Add a new panel by:

  1. Module-augmenting PanelMap with its id, panel type, params type.
  2. Calling register with a PanelProvider. Studio code never has to change.
