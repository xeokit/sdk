Class EmphasisMaterial

Configures the appearance of ViewObjects when they are xrayed, highlighted or selected.

  • Located at View.xrayMaterial, View.highlightMaterial and View.selectedMaterial.
  • XRay a ViewObject by setting ViewObject.xrayed true.
  • Highlight a ViewObject by setting ViewObject.highlighted true.
  • Select a ViewObject by setting ViewObject.selected true.
