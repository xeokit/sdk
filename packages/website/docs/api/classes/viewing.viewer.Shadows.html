Class Shadows

Configures directional shadow mapping for a View.

  • Located at Effects.shadows, which lives at View.effects.
  • Disabled by default. Set enabled to true or pass effects: {shadows: {enabled: true}} when creating a View.

See @xeokit/sdk/viewing/viewer for usage info.
