Class Shadows

Configures single-cascade directional shadow mapping for a View.

  • Located at Effects.shadows, which lives at View.effects.
  • View will cast shadows when View.renderMode is set to one of the values specified in Shadows.renderModes.

See @xeokit/sdk/viewing/viewer for usage info.
