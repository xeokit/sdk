Interface XGFStreamingRuntimeIndex

Compact runtime index for an XGF stream dataset.

This representation minimizes repeated JSON property names in large stream indexes. Decode it with readXGFStreamingRuntimeIndex before passing it to loaders or orbit navigation controllers.
