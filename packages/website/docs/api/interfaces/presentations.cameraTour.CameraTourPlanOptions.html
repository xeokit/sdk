Interface CameraTourPlanOptions

Tuning knobs for planCameraTour. Every field is optional; defaults target a typical AECO walkthrough at metre-scale.

Forwarded verbatim to the pluggable SpaceExtractor, ViewpointSampler, and TourPlanner so custom implementations can honour the same caller intent.
