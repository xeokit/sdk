Interface ProjectionBasis

Orthonormal {right, up, forward} basis used throughout the projection pipeline. Pixel u grows along right, pixel v grows along up, and the camera looks along forward from (conceptually) -infinity. All three vectors are unit length and mutually orthogonal.
