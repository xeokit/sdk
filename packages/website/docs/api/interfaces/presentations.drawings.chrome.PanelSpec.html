Optionalcolor

color?: Vec3

RGB tint applied to the panel. When PanelSpec.paint is also supplied, this multiplies the painter's colour texture. Default [1, 1, 1] (white — let the painter speak) when a painter is set; [0.96, 0.97, 0.99] otherwise.

Optionalpaint

paint?: () => MaterialMaps

Optional PBR painter — a zero-arg callback returning a MaterialMaps triple (colour + normal + metallic- roughness). When provided, the projector creates the three textures and a SceneMaterial inside the target SceneModel and binds the panel mesh to it.

The painter is called once per buildDrawing call. Cache the maps yourself if you're projecting onto multiple faces and want them to share one underlying texture set.

  • Defined in packages/sdk/src/presentations/drawings/chrome/PanelSpec.ts:31

OptionaltextureScale

textureScale?: number

World-space texture repeat distance, in scene units per tile. Forwarded to the SceneMaterial as triplanarScale, so the panel quad (which has no UVs) samples the painter's textures via the renderer's triplanar fallback. Default 1.0.
