Interface SpaceLabelSpec

Customisation for the per-space label pass of buildDrawing.

Phase 1 of the labelling system: emits text inside each eligible source object's projected fill polygon, anchored at the pole-of-inaccessibility (max-distance interior point). No leader lines or collision checks with other labels.

Eligibility is the intersection of:

  • The source SceneObject contributed a non-empty fill polygon for this drawing (so the projection had to be called with fill: true).
  • There is a DataObject in the supplied data graph with the same id, AND its type is one of dataTypes.
  • The fill polygon's bounding rectangle is at least minArea world units².

Typography defaults to all-caps single-line text, sized to a fraction of the inscribed circle's radius. Override fontScale to tighten or loosen the fit.

fontScale?: number

Label height as a fraction of the polygon's inscribed-circle radius (the radius of the largest circle that fits inside the polygon, centred at the pole of inaccessibility). Default 0.30.

Final font size is clamped to maxFontSize so giant atria don't end up with metre-tall text.
