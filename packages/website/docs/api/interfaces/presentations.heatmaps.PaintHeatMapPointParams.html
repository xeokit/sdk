Optionalfalloff

falloff?: number

Falloff exponent applied to the radial weight (1 - r/radius).

  • 0 — hard-edged disc (every pixel inside the radius gets full opacity).
  • 1 — linear falloff to zero at the edge.
  • >1 — softer, with most of the weight near the centre. Default 1.
