Interface GPUMemoryConfigs

GPU memory configuration options for the WebGLRenderer.

This interface defines the limits for various GPU memory allocations used by the renderer, such as the number of mesh batches, tiles, vertices, indices, geometries, meshes, and primitives. These values are used to optimize memory usage and rendering performance for 3D building models, especially those with geometry similar to IFC (Industry Foundation Classes) models.

interface GPUMemoryConfigs {

}

maxTiles

maxTiles: number

Maximum number of RTC (Relative To Center) tiles that can be allocated in GPU memory. A tile is a region of 3D space that holds RTC-relative vertex positions for a subset of meshes. Tiles break up the world space into chunks, allowing vertex positions to be stored and rendered with higher precision using single-precision coordinates relative to the tile origin.
