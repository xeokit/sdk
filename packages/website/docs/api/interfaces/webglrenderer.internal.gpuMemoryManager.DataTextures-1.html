Interface DataTexturesInternal

Collection of GPU data textures used by a WebGLRenderer.

DataTextures centralizes all GPU-resident data required for rendering, including:

  • Global, view-dependent textures shared across all render batches
  • Per-batch textures used for sorted, efficient draw submission

This object represents the renderer’s authoritative view of GPU-side data.

batches

batches: BatchDataTextures[]

Render batches for sorted rendering.

The renderer groups renderable meshes into batches that share compatible rendering state in order to minimize draw calls. Each batch owns a set of DataTextures containing all GPU-resident data needed to draw the meshes in that batch.

Each batch is drawn independently, with one draw call per render pass.

viewTileCameraMatrixTexture: MatrixTexture[]

Per-view tile camera matrix tables.

For each View, this array contains a DataTexture holding the RTC camera view matrices for that View in all tiles.

These textures are global and shared across all render batches.
