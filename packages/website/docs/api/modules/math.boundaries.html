Namespace boundaries

xeokit Boundary Math Utilities

Tools for 2D and 3D boundary analysis, transformations, and collision detection.

Features:

  • Axis-Aligned Bounding Boxes (AABB2 & AABB3)
  • Oriented Bounding Boxes (OBB)
  • Transformable OBBs
  • Boundary creation from positions
  • Center point calculations
  • Frustum projection and boundary intersection tests

Installation

npm install @xeokit/sdk

Usage

import { createAABBFloat64 } from "@xeokit/sdk/math/boundaries";

const aabb = createAABB3Float64([-100, -100, -100, 100, 100, 100]);
const aabb2 = createAABB3Float32([-50, -50, -50, 50, 50, 50]);
const aabb3 = createAABB3Int16([-25, -25, -25, 25, 25, 25]);
