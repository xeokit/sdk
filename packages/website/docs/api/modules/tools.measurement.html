xeokit Measurements

SVG + DOM overlay widgets that paint world-space measurements on a View's canvas — diagonal distance with X/Y/Z decomposition, and three-anchor angle in degrees.

The measurements module ships one tool per measurement type. Each tool is a long-lived overlay attached to a single View, owning a keyed collection of measurement instances. Optional mouse-control helpers turn canvas clicks into measurements without the caller having to connect pickers.


Sub-modules

  • distance — point-to-point 3D distance with X/Y/Z axis decomposition. Two-click creation via MouseDistanceMeasurementsControl.
  • angle — three-anchor (origin, corner, target) angle at the corner, in degrees. Three-click creation via MouseAngleMeasurementsControl.

Shape
