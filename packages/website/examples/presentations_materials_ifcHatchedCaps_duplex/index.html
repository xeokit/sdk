Duplex IFC loaded with procedural PBR materials via applyIFCMaterials — each IFC type also carries an ANSI/ISO hatch convention (steel for railings, ISO concrete for slabs, ANSI 31 wood for walls/doors, ANSI 38 dot for plaster furnishings, etc.). The view runs in DetailedRender so bodyHatch is active and the model body draws as engineering schematic (hatched Lambert), while the section plane's cap pass paints each cross-section with the same per-material hatch.
Toggle Mode to flip between DetailedRender (engineering schematic) and RealisticRender (PBR). Caps stay hatched in both modes — the cap fill is an engineering symbol independent of body shading.
