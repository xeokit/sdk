Duplex IFC loaded with procedural PBR materials via applyIFCMaterials, then sliced by a horizontal section plane. createSectionCaps walks every triangle-bearing mesh that the plane crosses, computes the cap polygon by stitching triangle-vs-plane segments, and emits filled TrianglesPrimitive meshes into a second SceneModel. Each cap mesh inherits its source material's hatchPattern, so in DetailedRender the caps draw with the same hatch as the body's surface.
The cap SceneModel's objects are marked non-clippable via view.setObjectsClippable, so the same section plane that slices the building leaves the caps intact on the cut plane.
