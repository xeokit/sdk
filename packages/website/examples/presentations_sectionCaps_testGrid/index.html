Section caps — generated test row

Twelve generated solids in a single row along world +X, all sliced by one horizontal section plane. The slider moves the plane up and down through the row; both the in-place caps and the lifted cap-preview row above update every input event.

Cap geometry renders twice:
  • In place at the cut plane (orange, embedded in the source row), marked non-clippable.
  • Lifted into a parallel cap-preview row above (also non-clippable) via the cap SceneModel's coordinateSystem.origin, recomputed each rebuild so the preview row's world-Z stays fixed while the cut sweeps.
