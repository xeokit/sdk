@xeokit/sdk

Welcome to the next generation of the xeokit SDK!

xeokit SDK V3 is a TypeScript toolkit for building web and Node.js applications that work directly with large AECO models. It brings together BIM and CAD viewing, federated model coordination, metadata-driven inspection, model conversion, point-cloud visualization, 2D drawing workflows and interactive presentation of engineering data.
