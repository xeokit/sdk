# Shared Example Libraries

This directory contains third-party browser assets and TypeScript libraries
shared by website examples.

Use this layer for reusable demo/application glue that should not become SDK API:

- camera rigs and example-specific adapters
- reusable demo flight dynamics and vehicle runtimes
- HUDs and screen overlays
- streaming-world helpers
- multiplayer/demo coordination
- browser-only controls and panels

Project-owned TypeScript libraries are split by role:

- `examples` - demo support such as aircraft, flight, physics, HUDs and other
  example-specific runtimes.
- `authoring` - reusable helpers for examples that author SceneModels,
  DataModels, geometry, objects and properties.
- `ui` - generic browser UI widgets used by website examples and Studio.
- `presentations` - higher-level presentation/demo features such as drawings,
  heatmaps, tours and sun studies.
- `studio` - the website Studio application shell, panels, dialogs and context
  menus.

Source files live under `libs/<name>/src/`. Runtime examples import built ESM
files from `libs/<name>/dist/`, generated by:

```bash
pnpm --filter @xeokit/website website-build-example-libs
```

`packages/website/scripts/build/build-example-libs.js` also supports per-example
entrypoints at `examples/<example-id>/src/index.ts`, bundled to that example's
`index.js`.
